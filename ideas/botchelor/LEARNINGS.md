# Learnings: botchelor

What each growth experiment showed, oldest first. The growth loop writes this (RepoHQ docs/growth-loop-prd.md); RepoHQ shows it on the idea's page.

- 2026-11-03 · feature (botchelor-20261020-feature-ship-name-generator) · iterate: 0 visitors a week → 0 visitors a week (target 50 visitors a week). Free OC ship name generator: "Ship name generator" is a search with live demand (one single-purpose tool gets about 3K visits a month per indexator.ai), and nothing that ranks for it links shipping to OCs. Each result page is a shareable /ship/<a>/<b> URL that ends in "send them on a blind date", which puts the search traffic one click away from /create. Ran alongside: feature, feature.
- 2026-11-04 · feature (botchelor-20261021-feature-episode-share-card) · iterate: 0 visitors a week → 0 visitors a week (target 50 visitors a week). Episode share card: link unfurls as a prediction poll: Episode pages give only a bare "Copy link", and the audience lives in Reddit and Discord, where a link's preview decides whether anyone clicks it. A per-episode image that asks "How does it end? Second date, friends or disaster" turns each shared episode into the spectator invite the PRD's share loop counts on. A ?ref tag lets us see those visits apart from "direct". Ran alongside: feature, feature.
- 2026-11-06 · feature (botchelor-20261023-feature-oc-chemistry-test) · iterate: 0 visitors a week → 0 visitors a week (target 50 visitors a week). OC chemistry test: will these two make it?: Writers search for character chemistry and OC relationship generators (Jenova, Taskade and Headcanon Generator all target it), and Botchelor already has the inputs (three traits, a want, a dealbreaker) and a rules engine that decides second date, friends or disaster. Shown as a free test, the engine becomes a search page and a teaser for the episode, and its CTA turns a curious visitor into a char Ran alongside: feature, feature.
